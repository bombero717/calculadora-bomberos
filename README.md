**Este repositorio no es la web.** Es el código fuente del proyecto. La aplicación en funcionamiento, para calcular tu jubilación, está en:

### 👉 [https://calculatujubilacion.es](https://calculatujubilacion.es)

Si buscabas la calculadora de jubilación, entra en el enlace de arriba.

---

## Qué es este repositorio

Código fuente (HTML/CSS/JS estático, sin backend) de calculatujubilacion.es: una web gratuita para estimar la edad de jubilación y el porcentaje de pensión en España, con motores de cálculo propios para distintos colectivos profesionales y una amplia base de fichas informativas sobre normativa de jubilación por profesión.

- 25 calculadoras con motor de cálculo propio, cada una implementando la normativa específica de su colectivo (bomberos, Policía Local, Guardia Civil, Policía Nacional, Fuerzas Armadas, Ferroviarios, Marina Mercante, Buzos, Toreros, Artistas, Jubilación Ordinaria, etc.), más centenares de fichas informativas para otras profesiones.
- Cálculo del coeficiente reductor aplicable y comparación automática con las vías de jubilación anticipada general (Arts. 207/208 LGSS) allí donde aplica.
- Despliegue estático vía GitHub Pages; el dominio público es calculatujubilacion.es.

## Privacidad del proyecto

- La aplicación publicada no requiere registro ni identificación del usuario.
- Los cálculos se ejecutan localmente en el navegador de quien usa la web; no se envían a ningún servidor.
- Ver [aviso legal](https://calculatujubilacion.es/aviso-legal.html) y [política de privacidad](https://calculatujubilacion.es/privacidad.html) de la web para más detalle.

> Los resultados de la calculadora son orientativos y no sustituyen el cálculo oficial de la Seguridad Social. La normativa puede estar sujeta a modificaciones.
