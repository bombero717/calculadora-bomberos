Privacidad

Información clara sobre los datos que introduce el usuario y el funcionamiento de la calculadora.

Una calculadora diseñada para funcionar en tu navegador

La calculadora no requiere crear una cuenta ni introducir un correo electrónico para realizar una simulación. Los datos necesarios para el cálculo se introducen directamente en el navegador.

En el código de la herramienta no se utiliza un formulario de envío de estos datos a una base de datos propia ni se ha incorporado un mecanismo de almacenamiento permanente mediante localStorage o sessionStorage.

¿Qué datos se introducen?

Dependiendo de la simulación, la calculadora puede utilizar datos como:

  • Fecha de nacimiento.
  • Tiempo trabajado en la profesión correspondiente.
  • Tiempo de cotización acumulado.
  • Situación laboral futura seleccionada para la simulación.
  • Otros datos necesarios para proyectar el cálculo.

Al generar el informe, el usuario puede introducir además opcionalmente un nombre, número de identificación interna y el servicio o unidad correspondiente. Estos datos se incorporan al documento que el propio usuario imprime o guarda.

¿Los datos de la simulación se envían a algún servidor?

La lógica de cálculo se ejecuta en el navegador. En el código revisado de la calculadora no se observa un mecanismo que envíe los datos introducidos mediante una petición fetch a una base de datos o servicio propio.

Esto significa que la finalidad de los datos introducidos es realizar la simulación en el propio dispositivo del usuario.

Importante: que la calculadora no envíe los datos de la simulación a un servidor propio no significa que una página web no pueda generar determinados datos técnicos de conexión en los servicios que intervienen en su publicación o carga. Consulta el apartado siguiente.

GitHub Pages y recursos externos

La calculadora está publicada como una página web estática en GitHub Pages. Como ocurre con cualquier sitio web alojado en un servicio de terceros, pueden existir registros técnicos propios del servicio de alojamiento, como información necesaria para atender solicitudes, seguridad, funcionamiento y diagnóstico.

La versión actual de la calculadora también carga recursos externos para su presentación, entre ellos Tailwind CSS y Font Awesome. La carga de esos recursos implica una conexión con los servicios desde los que se sirven dichos archivos.

Estos aspectos son diferentes de los datos que el usuario introduce expresamente en el formulario de la calculadora.

El informe PDF

El informe se prepara utilizando la información que aparece en la propia página y se genera mediante la función de impresión del navegador.

Cuando el usuario pulsa «Imprimir / PDF», el navegador abre su propio diálogo de impresión. Desde ahí puede seleccionar «Guardar como PDF» o la opción equivalente de su dispositivo.

El archivo PDF se guarda donde el propio usuario decida. La calculadora no necesita recibir una copia de ese documento.

Recomendación: si introduces tu nombre, número de identificación, servicio u otros datos identificativos en el informe, trata el PDF como un documento personal y guárdalo en un lugar adecuado.

No es necesario introducir datos identificativos

Para realizar una simulación no es necesario utilizar el nombre real del trabajador ni introducir un número profesional. Si quieres conservar el informe para uso personal, puedes identificarlo como prefieras.

Evita introducir en la calculadora información que no sea necesaria para el cálculo, especialmente datos de terceros.

Sobre esta información

Esta página describe el funcionamiento de privacidad de la versión actual de la herramienta. Si en el futuro se incorporan analítica, formularios, cuentas de usuario, almacenamiento en servidor, publicidad u otros servicios que modifiquen este funcionamiento, esta información deberá actualizarse.

Esta página tiene carácter informativo y no pretende sustituir el aviso legal o la política de privacidad que pueda resultar exigible al responsable del sitio en función de su situación jurídica.
