# Calculadora de Jubilación para Bomberos (España)

Herramienta web interactiva y gratuita diseñada para estimar la **edad de jubilación y el porcentaje de pensión** aplicable a los bomberos en España, de acuerdo con el coeficiente reductor previsto en la normativa de la Seguridad Social.

## Normativa aplicada

- **Real Decreto 383/2008, de 14 de marzo:** aplicación del coeficiente reductor del `0,20` por el tiempo efectivamente trabajado como bombero.
- **Ley 27/2011 y normativa posterior de pensiones:** criterios de edad ordinaria de jubilación y periodos de cotización exigidos según el año de jubilación.
- **Cómputo especial (Art. 4 RD 383/2008):** el periodo de reducción de la edad de jubilación se computa a efectos de determinar el porcentaje aplicable a la base reguladora.

## Características

- 100% gratuita y sin registro.
- Cálculo automático en tiempo real.
- Aplicación del coeficiente reductor del `0,20`.
- Estimación de la edad de jubilación y del porcentaje de pensión.
- Diseño responsivo compatible con móviles, tablets y ordenadores.
- Funcionamiento sencillo y sin necesidad de introducir datos identificativos.

> **Aviso:** Los resultados son orientativos y no sustituyen el cálculo oficial de la Seguridad Social. La normativa puede estar sujeta a modificaciones.
> 
## Privacidad

La calculadora está diseñada para proteger la privacidad del usuario.

- **No requiere registro** ni identificación del usuario.
- Los datos introducidos en la calculadora se procesan **localmente en el navegador** y no se envían a un servidor para realizar los cálculos.
- Los datos personales que el usuario puede introducir para generar el informe PDF se utilizan **únicamente para crear dicho documento**.
- El PDF se genera para el propio usuario y no se envía a ninguna plataforma ni servicio externo.
- La aplicación no utiliza una base de datos para almacenar los datos introducidos en la calculadora.
- No es necesario introducir nombre, DNI, correo electrónico ni otros datos personales para utilizar los cálculos.

> **Privacidad:** Los datos introducidos para realizar los cálculos y generar el informe PDF permanecen bajo el control del usuario y no se transmiten a un servidor de la aplicación.
